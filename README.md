---

## 这是什么？

一套专为**不会编程但想用AI开发项目**的用户设计的开发工作流。通过「策略AI + 执行AI」双窗口协作，把模糊需求拆解为可执行的阶段化操作，每一步都有明确的提示词、审查清单和状态标记。

你不需要懂代码，只需要会**复制粘贴**和**点确认**。

---

## 快速开始

**打开 `shutong-dev-workflow.html`，选择模式，按阶段复制提示词即可。**

```text
1. 打开两个AI窗口
   - 窗口A（策略层）：Kimi / ChatGPT / Claude — 审查方向、生成指令
   - 窗口B（执行层）：Mimo Code / Cursor / Copilot — 查代码、改代码、运行验证

2. 选择你的场景（三种模式）
   - 🆕 从零新建项目：没有代码，从头搭建
   - ➕ 新增功能/模块：有代码，要加新功能
   - 🔧 修复现有问题：有代码，功能坏了

3. 按阶段复制提示词，每步等确认
   - 每个提示词卡片有使用说明（发给谁、时机、预期结果）
   - 策略AI审查通过后告诉你下一步去哪
```

---

## 三种模式

### 🆕 从零新建项目

适用于没有任何代码，从头搭建的场景。

```text
初始化 → 设计 → 契约 → 编码 → 验证 → 部署 → 完成
```

### ➕ 新增功能/模块

适用于项目已有代码，要加新功能或新模块的场景。

```text
探测 → 设计 → 契约 → 编码 → 验证 → 完成
```

### 🔧 修复现有问题

适用于项目已有代码，功能坏了或行为不对的场景。

```text
探测 → 诊断 → 契约 → 编码 → 验证 → 完成
```

## 特性

| 特性 | 说明 |
|------|------|
| **3种模式** | 从零新建 / 新增功能 / 修复问题，覆盖常见开发场景 |
| **双AI纠偏** | 策略AI审方向 + 执行AI写代码，防止需求漂移 |
| **使用说明** | 每个提示词卡片标注：发给谁、时机、预期结果、下一步 |
| **一键复制** | 点击按钮直接复制提示词 |
| **右侧记事本** | 需求和笔记两个标签，localStorage持久化 |
| **暗色主题** | 护眼暗色界面，模式切换颜色跟随 |
| **检查清单** | 每个阶段底部嵌入人工复核检查点 |

## 核心原则

1. **策略AI不碰代码** — 只审查方向和完整性，不写代码
2. **一次只改一个文件** — 防止调用链断裂
3. **每步有状态标记** — 卡住时精准恢复
4. **不确定就停** — 任何异常立即停止，等策略AI判断

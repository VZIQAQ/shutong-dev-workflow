# 03 - CONTRACT：接口契约

> **阶段目标**：确认"新方法输入什么、输出什么、失败时怎么办"，防止执行AI幻觉字段名。
>
> 根据项目模式选择对应分支。

---

## 分支A：改造现有项目 → CONTRACT

### 执行AI提示词（发给窗口B）

```text
【阶段：CONTRACT】确认接口，不写代码，不执行命令。

【新增/修改模块】
- 输入：{{你期望的输入参数}}
- 输出：{{你期望的返回结构}}
- 失败时：{{你期望的失败行为}}

【现有数据结构】
- {{数据对象名}} 字段：{{列出PROBE中找到的实际字段}}

请回答：
1. 你项目里 {{相关结果对象}} 的实际字段有哪些？列出来。
2. 调用外部模型时，输出格式要求是什么？（JSON格式、字段名）
3. 如果新逻辑失败，降级路径是什么？调用哪个旧方法？输入输出是否一致？
4. 编码阶段是否一次只改一个文件？确认。
5. 前后端交互的API是否有变化？（如有前端改造）

确认后我回复"确认"，进入编码。
输出末尾加 [CONTRACT_DONE]
```

### 等待执行AI返回

你会收到契约确认（5个答案 + `[CONTRACT_DONE]`）。

把完整返回复制下来。

### 策略AI提示词（发给窗口A）

把 `{{执行AI的契约确认}}` 替换为你复制的内容：

```text
【CONTRACT审查任务】

请审查以下执行AI返回的契约确认。

## 执行AI的契约确认：
{{执行AI的契约确认}}

## 你的任务：

### 第一步：一致性审查
- [ ] 字段名与PROBE中贴出的数据结构一致（如 RelevanceDecision 的字段名）
- [ ] 降级路径明确（说了"失败时调用XX方法"）
- [ ] 编码纪律确认（执行AI明确说"一次只改一个文件"）
- [ ] 末尾有 [CONTRACT_DONE] 标记

### 第二步：输出下一阶段指令

如果审查通过，输出【CODE-文件1】指令（见 04-code.md）。
```

### 下一步

审查通过后，复制策略AI生成的【CODE-文件1】指令，进入 [04-code.md](04-code.md)。

## 分支B：从零新建项目 → CONTRACT

### 执行AI提示词（发给窗口B）

```text
【阶段：CONTRACT-从零】设计接口和数据模型，不写代码，不执行命令。

基于 DESIGN 阶段确认的架构设计：
{{粘贴DESIGN阶段确认的模块依赖图和数据流}}

【技术选型（已确认）】
- {{前端框架/后端框架/数据库/其他}}

请回答：
1. 【数据模型设计】核心数据实体有哪些？列出每个实体的字段名、类型、约束。
2. 【API接口设计】需要哪些接口？列出每个接口的路径、方法、请求参数、返回结构。
3. 【模块接口设计】各模块之间的函数/方法调用接口是什么？输入参数和返回值类型。
4. 【异常处理策略】每个模块的异常如何处理？是抛出还是捕获？错误码如何定义？
5. 【技术选型确认】请复述已确认的技术栈，确保我们理解一致。
6. 【编码纪律确认】编码阶段是否一次只创建一个文件？确认。

确认后我回复"确认"，进入搭建。
输出末尾加 [CONTRACT_DONE]
```

### 等待执行AI返回

你会收到接口和数据模型设计（6个答案 + `[CONTRACT_DONE]`）。

把完整返回复制下来。

### 策略AI提示词（发给窗口A）

把 `{{执行AI的契约确认}}` 替换为你复制的内容：

```text
【CONTRACT-从零审查任务】

请审查以下执行AI返回的接口和数据模型设计。

## 执行AI的契约确认：
{{执行AI的契约确认}}

## 你的任务：

### 第一步：完整性审查
- [ ] 数据模型有具体的字段名和类型（不是模糊描述）
- [ ] API接口有路径、方法、参数、返回值
- [ ] 模块接口有函数签名和类型标注
- [ ] 异常处理策略明确（错误码、抛出/捕获规则）
- [ ] 技术选型与INIT阶段确认的一致
- [ ] 编码纪律确认（一次只创建一个文件）
- [ ] 末尾有 [CONTRACT_DONE] 标记

### 第二步：一致性审查
- [ ] API接口的返回结构与数据模型字段一致
- [ ] 模块接口的参数类型与数据模型一致
- [ ] 错误码定义覆盖了主要异常场景

如果以上有任何一项未通过，输出【追问指令】。

### 第三步：输出下一阶段指令

如果审查通过，输出【CODE-骨架1】指令（见 04-code.md 从零模式）。
```

### 下一步

审查通过后，复制策略AI生成的【CODE-骨架1】指令，进入 [04-code.md](04-code.md)。
